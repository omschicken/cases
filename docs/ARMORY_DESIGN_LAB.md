# DROPZONE / THE ARMORY — Design Lab 01

## Asset audit

- `apps/web/src/assets/ak47.png` is a real raster asset already present in the project. It is used only as a supporting weapon silhouette in the hero.
- Existing catalog cases are primarily generated by `CaseMiniArt` from nested HTML/CSS surfaces. Their geometry is shared; slug data changes hue and glyph, so their silhouettes remain nearly identical.
- API `imageUrl` values are used when available, but the design lab does not depend on the API and does not claim generated weapon imagery as a real CS2 skin.

## New container system

The three case images are original product visualizations generated for DROPZONE. They represent containers, not CS2 weapons or skins.

| Case | Form | Materials | Light | Source |
| --- | --- | --- | --- | --- |
| Static Case | Low horizontal precision cassette | Graphite aluminum, bone ceramic, cobalt glass | Cold studio rim | `assets/armory/static-case.png` |
| Ignition Case | Tall thermal canister | Heat-treated steel, copper fins, carbon fiber, amber glass | Tungsten core | `assets/armory/ignition-case.png` |
| Dragon Case | Tall asymmetric reliquary | Titanium scales, pale stone, blackened brass, crimson glass | Museum spot and red edge | `assets/armory/dragon-case.png` |

All three files are RGBA PNGs with real transparent pixels. Intended master resolution is 1024–1536 px on the long edge. They are isolated objects with enough margin for responsive cropping and CSS shadows.

## Composition rules

- The hero uses one dominant case object and one existing project weapon asset.
- Static composition must remain strong without animation; motion is limited to hover elevation.
- Cards prioritize the object, name and price. Technical labels stay secondary.
- Four columns are shown on wide desktop: three finished objects plus a deliberately quiet classified slot.
- At 700 px and below the hero becomes object-first and cards become a single column.
- `prefers-reduced-motion` removes all transforms and transitions.

## Isolation

`/design-lab` exists only when `import.meta.env.DEV` is true. Its component, CSS and heavy image assets are loaded through a development-only lazy import and are absent from the production build output. No API, backend, economy, auth or production route was changed.
