## Выполненные проверки

- Каталог содержит ровно 15 активных записей и не включает старые неактивные `static-case` и `ignition-case`.
- Все 15 карточек ведут на канонический `/cases/:slug`.
- На всех 15 страницах совпали название, цена и количество отрисованных предметов с API.
- Все отображаемые вероятности сформированы из реальных `weight` текущего ответа API; у каждой карточки предмета есть процент.
- Бесплатное демо открылось на каждой из 15 страниц. Оно работает в гостевом режиме и не отправляет платный `/cases/open`.
- Ссылка возврата в каталог присутствует и работает на каждой странице.
- `static-case` отображается как неактивный: статус «Недоступен», платной кнопки у гостя нет, цена API сохранена.
- Несуществующий slug показывает «Кейс не найден».
- Desktop проверен при 1440×900; mobile — при 390×844.
- В консоли нет критических ошибок. Есть только существующие предупреждения React Router о future flags v7.

## Изображения, требующие замены

Новые самостоятельные case-art ассеты нужны для 11 slug:

`neon-rush`, `overdrive`, `sovereign`, `dragon`, `blacklight`, `aurora`,
`blacklight-case-v4`, `ignition-case-v4`, `sovereign-case-v3`,
`overdrive-case-v3`, `static-case-v3`.

Первые шесть используют текстовые placeholder 400×300. Последние пять используют изображение отдельного Steam-предмета 512 px вместо самостоятельной графики кейса.

Дополнительно первые десять активных коллекций содержат placeholder-изображения предметов, поэтому результат демо у них визуально остаётся временным. Это проблема исходных данных/ассетов, а не отображения Editorial Light.

## Ограничение проверки поиска

Параметр поиска `?q=` и фильтры были подтверждены в предыдущем прогоне коммита `168c326`. В текущем повторном прогоне автоматизированный ввод в поле поиска дважды не завершился из-за ограничения browser-control locator, поэтому третий способ не запускался. Остальные проверки выполнены фактически и перечислены выше.
